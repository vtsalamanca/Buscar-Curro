# Resultados públicos de Buscar Curro

Esta rama publica exclusivamente un subconjunto depurado de referencias a ofertas y huellas públicas. No se deben añadir credenciales, datos de aspirantes, historiales personales, solicitudes, ficheros brutos o comunicaciones privadas. Los resultados reales aparecerán en `notices/latest.json` después de una ejecución comprobada.

El origen del programa está en la rama `main`. La ausencia de `latest.json` significa **no hay ejecución verificada**, no que no haya ofertas.
