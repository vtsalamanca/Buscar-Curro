# Buscar-Curro — Catálogo geográfico de preselección (Nambroca)

**Versión inicial — 19/10/2026. NO ES UNA LISTA CERRADA NI UNA LISTA DE MUNICIPIOS DENTRO DE 75 KM.**
El usuario pide evitar cálculos repetitivos mediante un catálogo fijo. El origen de trabajo es **Nambroca (Toledo)**, límite ordinario **70 km por carretera**, margen opcional **70–75 km**. El catálogo siguiente es una **cola de candidatos geográficos**, que incluye localidades que pueden estar FUERA del radio. Ninguna fila sin distancia verificada se debe considerar automáticamente incluida o excluida.

## Fuentes e interpretación
- IGN / CNIG, nomenclátor oficial 2026 (nombre, coordenadas de municipios y núcleos): https://centrodedescargas.cnig.es/CentroDescargas/nomenclator-geografico-municipios-entidades-poblacion

- Red vial: una ruta desde centro urbano Nambroca hasta centro o dirección de destino; especificar perfil, proveedor, fecha, posible variación de recorrido. Distancia euclidiana NO equivale a kilómetros de carretera. Comprobar datos antes de clasificar.
- OSRM (router público) puede servir en pruebas puntuales no intensivas y con atribución OSM, pero NO debe asumirse servicio fiable gratuito para consultas masivas continuas: https://github.com/Project-OSRM/osrm-backend/wiki/Api-usage-policy

## Fase de cierre del catálogo (por lote técnico gratuito)
1. Descargar nomenclátor IGN 2026 y tabla INE; normalizar nombres, municipios y códigos oficiales sin inventarlos. Incluir pueblos, municipios y barrios de Toledo (Azucaica, Santa María de Benquerencia), identificados con su municipio matriz cuando proceda.
2. Georreferenciar el origen y las localidades oficiales; calcular distancia geodésica solo para **preseleccionar un conjunto amplio**, nunca para confirmar la distancia por carretera.
3. Comprobar por carretera con un motor gratuito permitido y un número de consultas prudente; cachear resultado y fecha. Incluir municipios limítrofes de Toledo, Madrid, Ciudad Real, Ávila y Cuenca que estén cerca del umbral, no solo los nombres aquí citados.
4. Clasificar: `hasta_70`, `margen_70_75`, `fuera_mas_75`, `pendiente`. Nunca clasificar `pendiente` como excluido. Conservar kilómetros, origen/destino, precisión, ruta y evidencia.
5. Crear CSV/JSON de lectura local para el programa y tests de normalización de acentos, duplicados, núcleos/polígonos, nombre ambiguo y nuevas localidades.
6. Filtrar anuncios por municipio con tabla en memoria. Para zonas/polígonos industriales con dirección conocida, comparar dirección real si afecta al límite.
7. Sólo usar lista cerrada cuando se hayan verificado municipios relevantes y exista mecanismo para manejar municipios desconocidos. No usar las estimaciones anteriores para exclusión automática.

**Regla crítica:** no sustituir cobertura por velocidad. La lista final debe ser completa para el alcance documentado o permanecer explícitamente provisional.
